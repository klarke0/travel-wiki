## How this is organised

Each trip folder follows the same shape, so any trip reads the same way:

| Page | What it's for |
|---|---|
| `index` | Dashboard — dates, what's booked, what's outstanding, links out |
| `itinerary` | **The plan.** Day by day. The only place a schedule lives, so it can't drift |
| *base town* | Reference for where you're staying — food, activities, hours, prices |
| *other places* | Day-trip options, each labelled scheduled or not |

Two rules that keep it usable:

1. **One schedule.** The itinerary is the single source. Never restate a plan on a
   destination page — link to it. Two copies drift, and the wrong one gets read.
2. **Research is kept, not culled.** Places you didn't end up going stay in full with a
   banner saying they're unscheduled. They're the menu when a plan falls through, and
   they're already researched next time you're in the area.

> 💡 Prices need escaping as `\$` — Quartz reads `$…$` as LaTeX and will silently eat
> anything between two dollar signs.
