# Dorado Beach, a Ritz-Carlton Reserve

**The splurge option.** Built on 50 acres of the old Rockefeller estate in Dorado, about
40 minutes west of the airport.

| | |
|---|---|
| **Config for 4** | **Two-bedroom residence**, full kitchen |
| **Ballpark** | **\$1,700–2,100 / night** |
| **Per person** | ~\$425–525 pp/night for four |
| **From SJU** | ~40 min |
| **Link** | [ritzcarlton.com](https://www.ritzcarlton.com/en/hotels/sjudo-dorado-beach-a-ritz-carlton-reserve/rooms/residences/) |

Butler service, three golf courses, two pools, indoor-outdoor rainforest showers.

**The catch:** there is nothing to walk to. It's a gated resort community, so you're
eating on property or driving. Fine if the plan is to sit still somewhere beautiful, poor
if you want to wander into dinner.
